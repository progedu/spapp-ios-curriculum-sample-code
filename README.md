# iOSアプリ入門講座 サンプルプロジェクト

このリポジトリは、教材で作成した **アプリのサンプルプロジェクト** を章ごとにまとめたものです。

各章は **独立した Xcode プロジェクト** になっており、該当章の内容をすぐに動かして確認できる構成になっています。

<br>

### 章一覧

| 章         | 内容                                 | 最終更新日 |
| ---------- | ------------------------------------ | ---------- |
| Chapter 01 | 開発環境を用意しよう（サンプルなし） |            |
| Chapter 02 | おみくじアプリ（Storyboard）                |            |
| Chapter 03 | おみくじアプリ（SwiftUI）    |            |
| Chapter 04 | いろいろなアプリ画面を作ってみよう   |            |
| Chapter 05 | ユーザ入力を使ってみよう             |            |
| Chapter 06 | データベースを使ってみよう           |            |
| Chapter 07 | API を使ってみよう                   |            |

<br>

### 開発環境

- Xcode 26.6
- macOS Tahoe 26.6.2 / Apple M4 Pro
- iPhone 12 Pro
- Swift / SwiftUI

<br>

### 使い方

1\. このリポジトリをクローン、または、ダウンロードする

```bash
git clone https://github.com/progedu/spapp-ios-curriculum-sample-code.git
```

2\. Xcode で chapter フォルダ配下の `.xcodeproj` を開く
